VICHY LITTÉRAIRE — КАК ЗАГРУЗИТЬ НА GITHUB

1. Загрузите в репозиторий все файлы и папку images.
2. В GitHub откройте Settings → Pages → Deploy from a branch → main / root.
3. Для своих изображений создайте папку images и добавьте файлы:
   letter-01.jpg
   letter-02.jpg
   ...
   letter-10.jpg
4. Письма редактируются только в файле texts.js.
   Новые письма добавляйте в начало массива window.VICHY_TEXTS.

ЯЗЫК ОРИГИНАЛА И ПЕРЕВОДЫ
В поле original можно сохранить письмо ровно в том виде, как его прислал автор.
В полях fr и en размещаются французская и английская версии.
Карточка всегда показывает первые два предложения оригинала.

SUPABASE — УЖЕ ПОДКЛЮЧЁН
Проект rbjcqarkoervxozboyry подключён в config.js.
Таблицы, защита RLS, хранилище документов, лайки, ограничение частоты отправки
и Edge Function send-letter уже созданы и опубликованы.
Secret key или service_role key во frontend добавлять нельзя.

ПОЧТА
Ключ Resend уже создан и сохранён только в секретах Supabase как RESEND_API_KEY.
Перед запуском сайта необходимо добавить свой домен в Resend и подтвердить DNS-записи,
затем сохранить в Supabase секрет:
MAIL_FROM="Vichy Littéraire <letters@ваш-домен>"

Тестовый адрес onboarding@resend.dev не может отправлять письма на
vichylitteraire@gmail.com: Resend разрешает это только после подтверждения домена.

После настройки Edge Function:
- сохраняет каждое письмо в таблице letter_submissions со статусом pending;
- отправляет полный текст на vichylitteraire@gmail.com;
- сохраняет текстовый документ в закрытом Supabase Storage;
- прикладывает оригинальный документ к email;
- показывает автору сообщение, что письмо скоро будет опубликовано.

КАРТИНКИ В ОПУБЛИКОВАННЫХ ТЕКСТАХ — ТОЛЬКО ДЛЯ РЕДАКТОРА
Посетители сайта не загружают фотографии.
Положите фотографию в папку images и укажите её в texts.js:
image:"images/letter-11.jpg"
Остальные поля этой же записи: author, place, original, originalLang, fr и en.

ЛАЙКИ
Лайки хранятся в общей таблице Supabase и одинаково отображаются у всех посетителей.
Для каждого браузера создаётся анонимный UUID. Ограничение UNIQUE не даёт одному
посетителю повторно увеличить счётчик одного письма.

ВАЖНО
Эта версия рассчитана на GitHub Pages и не требует сборки.
Файлы backend находятся в папке supabase.
